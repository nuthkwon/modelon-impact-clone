# License of the Modelica library shipped with this platform

The `Modelica` library in this directory is a **subset of the Modelica Standard Library
(MSL) 4.0.0**, adapted to the Modelica subset supported by this platform (no arrays,
functions, algorithm sections, redeclarations, conditional components, `inner`/`outer`
or `stream` connectors). Class names, icons, parameter names, units, descriptions and
equations follow the original library; simplifications relative to MSL are listed in
`docs/LIBRARY.md`. The original sources are available at
<https://github.com/modelica/ModelicaStandardLibrary>.
